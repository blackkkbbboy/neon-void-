# NEON VOID

A fast, neon-styled **space shooter** that runs entirely in your browser. No installs, no dependencies, just HTML, CSS and JavaScript.

**Play it:** `https://YOUR-USERNAME.github.io/YOUR-REPO/` (after enabling GitHub Pages, see below)

## Features

- Endless waves that get harder, with a **boss fight every 5th wave**
- 5 enemy types: drones, zig-zaggers, shooters, tanks and bosses with 3 attack patterns
- Power-ups: **T** triple shot, **R** rapid fire, **S** shield, **+** heal
- Particle explosions, screen shake and procedural sound (no audio files)
- High score saved in your browser
- Works on desktop and mobile

## Controls

| Action | Keys / Touch |
| --- | --- |
| Move | WASD, arrow keys, or drag with mouse / finger |
| Fire | Automatic |
| Pause | `P` or `Esc` |
| Mute | `M` |
| Start / restart | `Enter` or `Space` |

## Run locally

Just open `index.html` in a browser. That's it.

## Publish on GitHub Pages

1. Push these files to a GitHub repo
2. Go to **Settings > Pages**
3. Under **Branch**, choose `main` and `/ (root)`, then save
4. After a minute your game is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`

## Project structure

```
index.html   page and menus
style.css    neon styling
game.js      all game logic
```
